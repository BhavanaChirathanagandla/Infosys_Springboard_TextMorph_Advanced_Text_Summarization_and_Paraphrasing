📊 AI Readability Analyzer (Colab + Streamlit)
🚀 Overview

This project is a Streamlit-based AI application that runs inside Google Colab using ngrok tunneling.

It provides:

🔐 User authentication system

📄 PDF text extraction

📊 Readability analysis using NLP metrics

🧑‍💼 Admin dashboard

🌐 How It Works (Colab Setup)

Since Streamlit cannot run directly in Colab UI, this project uses:

Streamlit → for web app UI

ngrok → to expose the app publicly

Colab environment variables → for secrets

👉 The app runs on a temporary public URL generated by ngrok.

✨ Features
🔑 Authentication

Signup/Login system

JWT-based session handling

Password hashing with bcrypt

Admin role support

📊 Readability Analysis

Flesch Reading Ease

Grade Level

Word & Sentence Count

Complex Word Detection

📄 PDF Analysis

Upload PDFs

Extract text using PyPDF2

Analyze readability

📈 Dashboard

Interactive charts using Plotly

Admin view for user monitoring
